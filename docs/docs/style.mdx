---
title: Project Codex Style Guide
---
These "style guidelines" are used to keep the codebases of Project Codex clean and consistent.

**Basics**
- Indent uses 4 spaces

**Naming conventions**
- Modules and packages use singular names
- Choose sensible variable names, if not sure consult the [yarn naming guidelines](https://github.com/FabricMC/yarn/blob/1.21.11/CONVENTIONS.md).

**Java code style**
- Standard Java conventions apply
- Redundant language modifiers are omitted

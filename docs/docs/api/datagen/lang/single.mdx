Package: &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;com.codex.composer.api.v1.datagen <br/>
Canonical Name: com.codex.composer.api.v1.datagen.ComposerLanguageProvider

Client assets generation provider offering a ton of utility methods for generating languages.

Inheritors have to implement:
```java
void generate();

/* Optional to override, used in prefix(key, value), suffix(key, value) and surround(key, value) */
String prefix() default "";
String suffix() default "";
```
The class provides many methods for registering translations:
```java
void feature(FeatureHandle feature, String translation);
void feature(Feature feature, String translation);
void stat(Identifier identifier, String value);
void group(RegistryKey<ItemGroup> key, String value);

## Example Implementation:
**From Elixiry, for now unreleased mod made for Warfare SMP**
```java
public class ElixiryLanguageProvider extends ComposerLanguageProvider {
    public ElixiryLanguageProvider(FabricDataOutput dataOutput) {...}

    private static final List<...> potionTranslations = new ArrayList<>();
    private static final List<...> fullPotionTranslations = new ArrayList<>();

    @Override
    public void generate() {
        block(ModBlocks.WITCH_CAULDRON, "Witch's Cauldron");
        block(ModBlocks.ARCANE_LECTERN, "Arcane Lectern");
        group(ModItemGroups.ELIXIRY, "Elixiry");
        group(ModItemGroups.SCROLLS, "Arcane Scrolls");
        group(ModItemGroups.PAPERS, "Drenched Papers");
        item(ModItems.LEXICON_ARCANUM, "Lexicon Arcanum");
        add(ModItems.LEXICON_ARCANUM.getTranslationKey() + "_creative", "Lexicon Arcanum (Creative)");
        add(ModItems.LEXICON_ARCANUM.getTranslationKey() + "_creative_tooltip", "Creative-only lexicon that contains all brewing recipes.");
        item(ModItems.ARCANE_SCROLL, "Arcane Scroll of %s");
        item(ModItems.DRENCHED_PAPER, "Paper Steeped in %s");
        item(ModItems.CONCOCTION, "Concoction");
        item(ModItems.LARGE_BOTTLE, "Large Bottle");

        addPotionTranslations();
        addVanillaPotionTranslations();
        buildPotionTranslations();
    }

    private void addPotionTranslations() {
        add("nausea", trans("Potion of Nausea", "Splash Potion of Nausea", "Lingering Potion of Nausea", "Arrow of Nausea"), "Nauseatic Paper", "Nauseatic Scroll");
        [...]
    }

    private void addVanillaPotionTranslations() {
        add("empty", "Blank Paper", "Blank Scroll");
        [...]
    }

    private Quartet<...> trans(String potion, String splash, String lingering, String arrow) {...}
    private void add(String id, String paperTranslation, String scrollTranslation) {...}
    private void add(String id, Quartet<...> trans, String paperTranslation, String scrollTranslation) {...}
    private void buildPotionTranslations() {...}
}

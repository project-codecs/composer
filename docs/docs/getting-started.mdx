This is a guide for getting started with using Composer for mod development! If you're not looking for that, [go back](./) where you came from!

Installing composer is as easy as any other maven package, if not for some annoyances. This documentation will be for Composer 5 and up,
so if you are using any version older than that, please stop. If you REALLY need an old version of composer for some reason, look at old
commits on the Composer [GitHub](https://github.com/project-codecs/composer) to see what it needs.

Anyway, here's install guides for all your favourite package managers: <br/>
Replace `(latest_version)` with the latest Composer version compatible with your Minecraft version.

Also, importantly Composer needs a fairly new version of loom (0.17+), and gradle as well (9.5.0+)

<details>
<summary>Gradle (Groovy DSL) - build.gradle</summary>

```properties
# gradle.properties
composer_version = (latest_version)
```

```groovy
// build.gradle

repositories {
    maven {
        name = "Composer Maven"
        url = "https://dl.cloudsmith.io/public/project-codex/composer/maven/"
    }

    maven {
        name = "Ambarela Maven"
        url = "https://dl.cloudsmith.io/public/project-codex/ambarella/maven/"
    }
}

dependencies {
    modImplementation "com.codex:composer:$composer_version+mc$minecraft_version"
}
```

</details>

<details>
<summary>Gradle (Kotlin DSL) - build.gradle.kts</summary>

```properties
# gradle.properties
composer_version = (latest_version)
```

```groovy
// build.gradle.kts

repositories {
    maven("https://dl.cloudsmith.io/public/project-codex/composer/maven/") {
        name = "Composer Maven"
    }
    maven("https://dl.cloudsmith.io/public/project-codex/ambarella/maven/") {
        name = "Ambarela Maven"
    }
}

dependencies {
    modImplementation("com.codex:composer:$composer_version+mc$minecraft_version")
}
```

</details>
